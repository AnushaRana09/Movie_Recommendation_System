**Movie Recommendation System**

**Project Overview:** A Machine Learning project that recommends movies similar to a user's selected movie using content-based filtering.

**Objective:** To build a movie recommendation system that analyzes movie genres and descriptions and recommends similar movies based on their content.

**Technologies Used**
- Python
- Pandas
- Scikit-learn
- TF-IDF Vectorization
- Cosine Similarity
- Google Colab
- Jupyter Notebook

**Dataset:** The project uses a custom dataset containing 40 movies with their genres and descriptions.

**Methodology**
1. Create and load the movie dataset
2. Combine movie genres and descriptions into features
3. Convert text features into numerical vectors using TF-IDF
4. Calculate similarity between movies using cosine similarity
5. Build a recommendation function
6. Search for a movie using the interactive interface
7. Display the selected movie's details
8. Recommend the top 5 similar movies

**Features**
- Movie search
- Partial movie-name matching
- Movie details and genre information
- Top 5 movie recommendations
- Similarity scores
- Multiple-match handling
- Movie-not-found handling

**Result:** The system successfully recommends movies based on the similarity between their genres and descriptions.

**Project:** Developed as part of an AI/ML Internship.
